# SHL Grammar Scoring Engine

## Overview
This project was developed for the SHL Research Engineer hiring assessment. The objective is to predict grammar scores for spoken audio samples.

## Approach
- Audio feature extraction
- Speech transcription and text-based feature extraction
- Machine learning regression models
- Cross-validation and model evaluation
- Ensemble predictions for the final submission

## Evaluation
The models were evaluated using out-of-fold predictions and metrics including RMSE and Pearson correlation.

## Files
- `shl_grammar_scoring.ipynb` — notebook containing the implementation and experiments.
- `submission.csv` — final prediction file, if permitted by the competition rules.

## Reproducibility
Open the notebook in Google Colab and follow the cells in order. Install the required dependencies and configure the dataset paths before execution.
